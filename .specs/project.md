## Vision

**What the project does:**
A local CLI tool for developers who use cron on their machine but have zero visibility on scheduled tasks. Cronshed provides a central `tasks.json` manifest, a `tasks/` script directory, and CLI skills (`/sched.*`) to create, monitor, diagnose, and manage cron jobs without leaving the terminal.

**The core problem it solves:**
`crontab -l` is opaque — no history, no error tracking, no next-execution visibility. Developers have no way to know if their scheduled scripts are running, failing silently, or misconfigured.

**Success in 2 years looks like:**
All personal cron jobs managed through Cronshed with full execution history, instant error visibility, and Telegram alerts on failure. A natural part of the daily dev workflow — checked as routinely as `git status`.
